# Smartfuel 
AI-Powered Smart Fuel Management System
## About the project 
SmartFuel is a web-based platform designed to make fuel ordering and fuel station management easier. It connects customers, station managers, administrators, and delivery personnel in one system.
## Key Features
- Customer Registration and Login
- Online Fuel Ordering
- Admin Dashboard
- Station Manager Dashboard
- Fuel Availability Management
- Delivery Management
- Order Tracking
# User Roles
- Customer
- Admin
- Station Manager
- Delivery Boy
## Project Goals
The main goal of SmartFuel is to make fuel management easier, faster, and more efficient through a digital platform.
## Technologies
- Frontend: React, JavaScript
- Backend: Python
- Database: SQlite
